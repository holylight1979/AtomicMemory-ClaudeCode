## 知識

- [臨] 使用者原話：「你知道你很像是在自言自語嗎? 因為 prompt 是你給的、建議也是你給的.. 按照"我要的"語意而言，你的"側寫認知"好像就又非靜默你自己會昇華、而是必須透過chat出來..」
- [臨] 始末：我給了下一階段 prompt（從「階段 3」開頭、只挑原始需求幾段、規矩比目標長、不要求重判優先序），使用者問「能確保不把視野越做越小嗎」，我才在 chat 裡批判自己的下一階段 prompt、再問「要不要我照這個方向改」。同一個 session 才剛做出「交出下一階段 prompt前先問還對得上大計畫嗎」的關鍵點，自己就沒做。
- [臨] 判準：自己的產出（下一階段 prompt、計畫、清單、接續單）交出前就要自己做側觀批判（用最上層原始目標看它會不會把視野縮小、手段有沒有蓋過目標），發現的問題直接改進檔與機制；問使用者要不要修自己的產出，等於把該自動的事推給人。chat 只報改了什麼。
- [臨] 跨 session 的認知不要靠下一階段 prompt攜帶：下一階段 prompt是上一個 session 寫的，它的盲點會一路傳下去。認知放在接續單（規矩、推進方式、最上層原始目標與這次的件），下一階段 prompt只指路。

## 行動

- 交出下一階段 prompt／計畫／清單前：用最上層原始目標檢查它會不會把視野縮小、有沒有要它重判優先序、規矩是不是比目標長
- 發現自己產出的缺陷：直接改檔、改機制，chat 只報改了什麼，不問要不要改
- 換手時把最上層原始目標與這次的件寫進接續單，下一階段 prompt只一句指路
