## 知識

- [臨] 使用者原話（兩題盲測答案公布後）：「BC兩題預測都錯，因為都在噴技術口水，一點具體建設性都沒有」。答案的形狀都是一句操作：題 B「以造出來的新輪子必須與舊的功能一樣、而且要更好來重構」；題 C「建跨廠商 LLM 溝通識別規格，且每一輪的跨 LLM 要有企劃、美術、程式、跨單位命題的交錯」。
- [臨] 我們交的是「現況長這樣、鏈有幾層、障礙有哪些、第一步切哪」的診斷。尺（原話輯 G7「重構出結果一樣但簡單幾百倍」、G9 多 LLM 等價認知）都讀了、引了，卻放在段尾一句帶過，標題給了形狀與障礙表。跟題 A「分辨了是時機不是方向錯、下一句仍不碰」同一個病：缺口不在尺有沒有送到，在送到之後要求回什麼形狀的答案。
- [臨] 染源不只專案現況：題 C 把「磨合文件」讀成要砍的雞肋，是因為研究者這幾天的 session 脈絡（開工單、記憶卡）全是雞肋判準，子代理拿它當尺。AI 自己剛讀過的判準名詞也會染「從零最簡形狀」。

## 行動

- 設計／方向題的結論第一句要是動詞（造什麼、建什麼、換什麼）加「怎麼證明一樣且更好」；形狀與障礙表是過程，不是答案
- 寫從零最簡形狀只用使用者世界的名詞，也不用自己這場剛讀過的判準名詞（雞肋、障礙、部位…）
- 引了尺之後回頭檢查：結論句有沒有真的照尺說的做，還是引完就放
