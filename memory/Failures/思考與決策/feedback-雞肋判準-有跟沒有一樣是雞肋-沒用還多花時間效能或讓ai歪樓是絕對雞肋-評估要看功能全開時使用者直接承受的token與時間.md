## 知識

- [臨] 使用者原話：「雞肋 的定義除了 "有與沒有幾乎一樣甚至更差" 以外，如果 "不但沒用 消耗效能、時間還增加了、或導致歪樓了" 就是絕對雞肋。」「問雞肋是在找 產品內還有什麼有跟沒有一樣、根本就可以拔掉的。」
- [臨] 評估目的（原話）：「"一旦正式對所有人開啟"，專案內團隊成員會直接承受到：token 是否會常造成不必要的消耗；簡單工作會不會變成老是消耗過長的時間；寫 code／非寫 code 的影響通通抓出來。」
- [臨] 做法：每個零件判四級（絕對雞肋／雞肋／有用／不確定），證據只用現在的程式加改完之後的實跑，絕對雞肋要附多了幾秒幾輪或帶去做了什麼；簡單工作（改一行、問一句、改文件）要單獨量。
