## 知識

- [臨] 使用者指正：開發期驗證不是「能免則免」，是「下在刀口上」——花在真正不確定、改錯會影響所有 session 的地方（例：每次工具呼叫都經過的 hook 要證守門開關兩種輸出都不變），不重要的就不跑。
- [臨] 「既然重要，決定質量的次數不應減」：嫌慢時不眨次數，改把對跑、計時、測試拆給不同 agent 並行；計時跟別的工作同時跑要新舊交錯輪替，讓搭 CPU 的干擾兩邊一樣。

## 行動

- 安排驗證前先寫「這次的刀口在哪」；嫌慢就拆工，不減次數
