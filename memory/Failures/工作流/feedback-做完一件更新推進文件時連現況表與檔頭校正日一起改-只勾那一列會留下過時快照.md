# feedback-做完一件更新推進文件時連現況表與檔頭校正日一起改-只勾那一列會留下過時快照

- Scope: global

- Quote: 「checklist文件你有更新嗎??」

- Trigger: checklist, 核心推進文件, 接續單, 現況表, 更新文件, 收尾更新, 過時快照, 你有更新嗎
- Created-at: 2026-10-16

## 知識

- [臨] 現象：做完一件後只改了 checklist 裡跟這件有關的幾列（打勾、備註 commit），同一份文件的「現在狀態」表還停在前幾天的快照（舊 main、舊「沒有工作樹」），檔頭「現在校正到』的日期也沒動；接續單現況段也留了一句過時的「沒有任何工作樹」。使用者追問「checklist 文件你有更新嗎」才補。
- [臨] 做法：收尾更新推進文件時，除了那一列，還要 grep 三類會過時的地方：①現況表（main commit、工作樹、別的 session）②檔頭或段頭的「校正到 <日期>」③別段寫死的舊狀態句（「沒有任何」「還差一件」）；沒能一起校正的段落就標明「只校正到哪天、之後看哪裡」，不留看起來像現況的舊快照。

## 行動

- 收尾改推進文件前，grep 舊 commit 號、「校正到」、「沒有任何」、「還差」這類字樣，一起改或標歷史
- 做完更新後自問：下個 session 只讀這份的現況段，會不會得到錯的現況
