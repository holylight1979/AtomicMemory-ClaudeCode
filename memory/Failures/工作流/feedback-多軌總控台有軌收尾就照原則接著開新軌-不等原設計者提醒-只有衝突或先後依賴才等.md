- Created-at: 2026-10-21

## 知識

- [臨] 原設計者原話：「除非像是先前我曾經說的 session 派工之間必須等（衝突或先後必須），否則就請你持續多開加速完工」「每次有收尾的 session，就不要讓我一直提醒了，自己該開就持續接著按原則開」。
- [臨] 判準：每收一軌就問「並行上限還有名額嗎、待辦裡哪件不跟在跑的軌撞檔」，有就當回合派；只有同檔衝突或先後依賴（例：要等某軌合完才能接線）才等，等的理由寫在派工單。
- [臨] 工人模型用 Opus（console-spawn --model claude-opus-5-5），除非絕對必須才用 Fable；effort 目前 spawn 工具沒有參數，吃 session 預設。

## 行動

- 收一軌 → 同回合盤名額與不撞檔的待辦 → 直接派，回報裡寫開了什麼
- 撞檔的拆成兩單：不撞的先開、撞的等合完
