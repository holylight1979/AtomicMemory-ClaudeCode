## 知識

- [臨] 使用者明令（2026-08-25）：長時間靠 inbox/信件來回推進的工作，**每一個 CC 回合都要先重新校準全盤落地現況**、評估偏移與過度細節指標，避免無止盡自檢、雞肋重驗、對一眼能看完的事過度研擬。可多開 agent 做盤點。
- [臨] **Why**：信件來回每封都把注意力拉到局部，局部的發現又誘發局部的追查，十封後風向就飄了（Phase B 實證：70+ 封，多輪在逐段 ack 與支線追查）。**How to apply**：回合開頭三行——目標一句（對照驗收檔）/ 現況差三件 / 偏移指標（①連續≥ 2 封無交付物 ②處理層級比 Phase 目標細一層以上 ③重驗已綠），任一命中即拉回主線；自檢只在收工做一次；全盤盤點量大時交給 agent 回摘要。

## 行動

- 監工型回合開頭先寫三行校準，再讀信/動手
- 偏移指標命中就把支線寫進清單、回主線
