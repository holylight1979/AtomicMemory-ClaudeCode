## 知識

- [臨] 使用者原話：「你卻一直壓著我要做裁定。我反而覺得應該要樹立『如果使用者對同一個問題久久無法裁定、AI 應該要嘗試各種方法來解釋，包括更加白話』…我反而覺得這種情況反而可能會讓 AI 自己發現自己有什麼搞壞掉了。」同則：「之前不是有說過要算的僅對實際產品會造成的影響嗎?這種開發期的驗證幹嘛抓token」
- [臨] 判準：同一題問第二次仍沒被裁定，不要再列選項或催拍板；改用一句話說清「這東西實際在做什麼」，說不出來或要拐很多彎，就是設計本身有問題，先找出哪裡壞。開發期驗證花的 token 不拿來問使用者；量測只報產品本身的差別。

## 行動

- 同一題第二次沒被裁定：停止催，換方法、更白話解釋，用解釋去找自己哪裡壞
- 開發期驗證的 token 不列進問句，該跑就跑
