## 知識

- [臨] 使用者原話：「你有沒有發現你是這三 session 會議與出文件的總控端？適度的要請他們利用沒事幹的時間做解決問題的事情，還要問他們有沒有新進展，或者叫他們跟你分工寫文件…怕寫文件打架就先分開寫之後再統一彙整。」背景：三方信箱討論我當根層，一直只回信、等信、自己寫整份文件，連寫十幾封「三方無待答項」，其實是沒派工。
- [臨] 主持端的三件事：①派工——每個 session 隨時有待辦（勾選清單、有編號），閘置就是派工失職；②問進度——定節奏（完成寄 report、未完成每 30 分鐘一行、沒事寄待命），主持端每 60 分鐘對帳；③分工寫文件——每人寫自己那段到各自的檔（attachments），固定小節格式，主持端彙整後再給各段作者核一次；分開寫就不會打架。

## 行動

- 當多 session 討論的主持端：每封信最後檢查「對方現在手上有沒有待辦」，沒有就派
- 寫「無待答項」之前先問：是真的沒事，還是我沒派？
- 共同文件一律分段分檔寫、主持端彙整
