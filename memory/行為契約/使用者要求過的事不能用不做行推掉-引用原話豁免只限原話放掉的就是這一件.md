# 使用者要求過的事不能用不做行推掉-引用原話豁免只限原話放掉的就是這一件

## 知識

- [臨] 判準：先看被推開的那件事，使用者原話裡是不是本來就要求做——是的話它就是任務本身，不能寫成追蹤行或不做行推掉，只能現在做。
- [臨] 收尾說某件沒做、引使用者原話當依據時，原話要明確叫你放掉「這一件」：原話的受詞要就是這件事。原話裡的「先這樣」講的是別件事時，不能拿來套。
- [臨] 程式不替你對受詞：使用者本人打「先這樣／跳過」會整份清掉紅測清單（不分哪一支），退避偏測對帶使用者引用的不做行也照收、不核原句。閘不擋不代表那件被放掉了。
- [臨] 反例：使用者要求 X 和 Y，後來說「Y 先這樣」，AI 收尾寫「X 沒做：使用者說「先這樣」」——使用者放掉的是 Y 不是 X。

## 行動

- 推開前先回頭看原話：這件是不是使用者要的？是就做
- 引用前確認原句的受詞就是這件事
