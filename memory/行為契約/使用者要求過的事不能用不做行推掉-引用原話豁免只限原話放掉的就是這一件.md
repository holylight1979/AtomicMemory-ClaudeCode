# 使用者要求過的事不能用不做行推掉-引用原話豁免只限原話放掉的就是這一件

- Entry: E09

## 知識

- [臨] 判準：先看被推開的那件事，使用者原話裡是不是本來就要求做——是的話它就是任務本身，不能用不做行推掉，只能現在做。
- [臨] 「不做｜<事>：使用者說「…」」只有在原話明確叫你放掉「這一件」時能用；原話的受詞要就是這件事。原話裡的「先這樣」講的是別件事時，不能拿來套。
- [臨] 反例：使用者要求 X 和 Y，後來說「Y 先這樣」，AI 寫「不做｜X：使用者說「先這樣」」——程式會放行，但使用者放掉的是 Y 不是 X。

## 行動

- 推開前先回頭看原話：這件是不是使用者要的？是就做
- 引用前確認原句的受詞就是這件事
