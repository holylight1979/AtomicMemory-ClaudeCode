## 知識

- [臨] Claude Code 內建的 Bash 安全檢查會擋 `rm -rf $VAR/…`：變數是空的時候這會變成刪根目錄，加權限規則也放行不了。
- [臨] 改寫就會過：用字面絕對路徑，或寫 `rm -rf "${VAR:?}"/…`（變數空就直接報錯、不執行刪除）。

## 行動

- 刪除指令要用變數組路徑時一律寫 `"${VAR:?}"/…`；被這道檢查擋下時不去加權限規則，直接改寫指令
