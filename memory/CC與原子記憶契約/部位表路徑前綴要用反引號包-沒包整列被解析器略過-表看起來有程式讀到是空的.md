## 知識

- [臨] 始末：聯合驗收題組手寫三個小專案的 `.claude/overview-map.md`，路徑前綴欄寫成 `notify/`（沒反引號），hook 與 commit 前病形閘都把整張表當空的：部位對不到、病灶文件的 shape 不套、導讀卡不送，但 AI 自己讀檔會以為表存在。根因：`lib/overview_hub.parse_map` 只認反引號包起來的路徑 token（`_BACKTICK_RE`＋`_is_path_token`）判哪欄是前綴欄；沒有反引號的列被當表頭或略過。
- [臨] 判法：寫完部位表先用 `python -c` 呼 `overview_hub.parse_map` 印 rows 數，或看 hook 注入有沒有「【部位名】」字樣；表上有列、rows 為 0 就是格式沒被認。病灶清單欄要填病灶文件的相對路徑（表裡每列 `shape: <regex>`），寫散文閘讀不到。

## 行動

- 手寫或生成部位表：路徑前綴一律反引號包；寫完用 parse_map 驗 rows 數 > 0
- 病灶清單欄填病灶文件路徑，形狀寫 `shape: <regex>`，不寫散文
