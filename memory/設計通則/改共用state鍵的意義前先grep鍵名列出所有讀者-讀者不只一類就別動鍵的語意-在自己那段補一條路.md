## 知識

- [臨] 要改一個共用 state 鍵（多段程式都讀的欄位、名單）的意義之前，先 grep 鍵名列出所有讀者，逐一問改了它這段會不會記錯，再決定改在哪。讀者通常不是呼叫者，grep 函式名找不到它們。
- [臨] 實例：記「這張卡送過了」的 injected_atoms 名單至少有四類讀者——搜尋段排除、失念偵測（記「該想起沒想起」）、情節摘要、交接。為了讓某段能補送一張卡就把它移出名單，失念偵測會把它記成沒想起的假帳。
- [臨] 做法：讀者不只一類時，鍵的語意不動，在自己那段補一條路（這例：組裝段從全池補回候選），影響只留在自己那段。

## 行動

- 改共用鍵／欄位的意義前 grep 鍵名列出所有讀者，逐一判會不會記錯
- 讀者不只一類就不動鍵的語意，改在自己那段
