# 要求證據晚於最後一次改動的閘-若採納它的意見本身就算改動-就會無限連鎖-要定成每次宣告最多要一次

## 知識

- [臨] 判準：一道關卡要求「證據要晚於最後一次改動」（審查、收據、對照），而照它的意見修正又算改動，就會形成「審→改→過期→再審」的無限連鎖。實例：第二意見用「晚於最後一次改碼」判欠不欠，採納 codex 意見後改碼就又欠一次。
- [臨] 修法：每次宣告完成最多要求一次；為採納意見所做的後續修改不再欠，寫下分歧與採納即可；只有後來又碰到「新的」高風險範圍才算新一輪。不分改動大小，會連鎖的就不能用（使用者裁定）。
- [臨] 同類要一起查：收據作廢→收尾欠帳→重跑再收尾（每命中一次多一回合）、改了就重交對照、擋了又擋的定位。加閘前先問：照它的要求做完，它自己會不會再觸發？

## 行動

- 設計或審任何「要求新證據」的關卡：寫出「照做之後會不會再欠」的案例，會就改成一次為限
