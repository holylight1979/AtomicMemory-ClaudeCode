## 知識

- [臨] 實例：沒樹時要判一筆寫入算不算「記憶知識類」，先寫成「不是程式檔就算知識類」。兩邊都錯：`git mv src pkg` 的寫入目標「src」是已消失的目錄、沒副檔名 → 判成不是程式 → 誤當知識類寫入（既有搬移案抓到）；改成「寫完還在的檔案才算」又讓 `rm old.md`、`mv docs old-docs` 這類整理動作完全沒留紀錄（Codex 抓到）。
- [臨] 判準：分類要用正面、查得到的事實逐格判（還在的檔看副檔名與部位、還在的目錄看裡面有沒有程式、已不在的路徑看副檔名），並明確留一格「分不出」（沒副檔名又不在），那一格不硬歸任何一邊；補集式定義（不是 A 就是 B）會把所有分不出的情況悄悄塞進 B。
- [臨] 同類檢查：寫完判定後拿『目錄、已刪除、搬走的來源與目的、沒副檔名的腳本、執行期資料（Logs、state、快取）』五種邊界各跑一次，看每種落在哪一格、是不是想要的。

## 行動

- 寫『X 算不算 Y』的判定前，先列出分不出的情況，給它自己一格
- 用補集（not is_x）當分類條件時，停下來換成正面事實逐格判
