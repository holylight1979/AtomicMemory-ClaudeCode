## 知識

- [臨] 判一層有沒有作用，問「把這一層拿掉、讓上下兩層直接相連，有沒有任何呼叫者、測試或行為會變」。沒新增、沒覆寫、沒人 isinstance 或型別註記用到、只轉手的那層＝沒有作用（常是抄舊架構或替「以後」預留），答「這一層沒有作用」並寫收法。反例：中間層加了幾個子類別共用的重試與逾時處理，拿掉就要在每個子類別各抄一份——它有作用，答「不會」並點出它加了什麼。
- [臨] 巢狀 3 層：三層若各守一個獨立條件（例：檔案存在／格式正確／未過期），讀者要同時記三件事 → 改 guard clause／early return 壓平；三層若是同一個局部決策（迴圈裡包一個 try 裡的單一判斷）仍能直線追，可保留但要說出為什麼。「還沒到 4 層」不是理由。
- [臨] 「既有架構就是這樣」「以後可能會用到」「繼承 3 層還在警戒線內」都不是理由；理由要指得出這一層此刻替誰做了什麼。

## 行動

- 每條先答「拿掉這層誰會壞」，再填五欄
- 有作用 → 第二欄寫它加了什麼；沒作用 → 第五欄寫具體收法（誰直接繼承誰、哪段改 early return）
