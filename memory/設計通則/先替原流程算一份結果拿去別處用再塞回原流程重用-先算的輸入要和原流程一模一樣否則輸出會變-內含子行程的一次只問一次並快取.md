# 先替原流程算一份結果拿去別處用再塞回原流程重用-先算的輸入要和原流程一模一樣否則輸出會變-內含子行程的一次只問一次並快取

## 知識

- [臨] 先替原流程算一份結果拿去別處用、再把這份結果塞回原流程重用時，原流程的輸出可能跟著變，原因是先算時給的輸入跟原流程自己算時不完全一樣。
- [臨] 例：收尾閘擋下之前，先算一份「後面還會擋哪些」的預覽拿閘名，再把預覽塞回原流程；預覽靠擋訊息裡的標記排除自己，先算時給的文字沒有那個標記，擋訊息就多出一行自己。
- [臨] 做法：要嘛先算時給跟原流程一模一樣的輸入，要嘛兩邊各算各的、不共用。
- [臨] 共用的計算裡若有子行程（例如 git），一次收尾只問一次並快取；不然連子行程的呼叫次數都會變，錄音重播（把子行程輸出錄下來給測試回放）會對不上。

## 行動

- 要重用一份先算好的結果：先比對先算時的輸入和原流程的是否完全相同，不同就各算各的
- 共用的計算裡有子行程呼叫：同一次流程只呼叫一次並快取
