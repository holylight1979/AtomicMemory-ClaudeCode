## 知識

- [臨] regex 寫成 `(?:^|[;&|(\n])\s*cd` 這種「行首或分隔符、接任意空白、再接關鍵字」的形狀，碰到一長串換行、後面又沒有 cd 時會二次方回溯：一萬六千行要 8.9 秒，超過 hook 上限 5 秒。
- [臨] 原因：每個換行都是一個起點，起點吃掉一個換行後 `\s*` 又跨行把後面的換行全吞掉，比不到關鍵字再一路退回來；n 個起點各退 n 步。
- [臨] 修法：空白只吃同一行的 `[ \t]*`，換行改由 re.MULTILINE 的 `^` 處理，比對回到線性。

## 行動

- 寫「行首或分隔符＋空白＋關鍵字」的 regex：空白用 `[ \t]*` 不用 `\s*`，配 re.MULTILINE 的 `^`；用一萬行以上只有換行的輸入量一次耗時
