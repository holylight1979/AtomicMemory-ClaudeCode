## 知識

- [臨] 判「這回合要不要跑交付檢查」不能只看措辭（有沒有說完成）或「本回合有沒有改檔」：前幾回合改過程式、這回合不說完成、只呼叫收尾類工具，也是交付邊界，兩種判法都會漏掉。
- [臨] 要用工具事實（這回合交了收尾檢核）加 session 事實（本 session 改過程式）一起認；只有整個 session 完全沒改程式（例：續接單匯入的舊樹）才豁免。「只在某類回合啟動」的守門是另一件事，那邊要認本回合訊號，別套過來。

## 行動

- 寫「是不是交付」判法時列出：前回合改、本回合只交收尾工具的案例要判成交付
- 豁免條件用 session 級「完全沒改程式」，不用措辭
