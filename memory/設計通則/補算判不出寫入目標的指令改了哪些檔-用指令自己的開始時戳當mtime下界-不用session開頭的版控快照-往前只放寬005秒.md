## 知識

- [臨] 要補算「一條判不出寫入目標的指令」改了哪些檔：拿這條指令自己在 transcript 裡的開始時戳當 mtime 下界，只收比它晚改的檔；比在 session 開頭拍一份版控狀態快照、事後比差異準。
- [臨] 快照法會把兩次查詢之間使用者、別的 session 的改動全算成這條指令的；時戳法只收指令跑的那段時間。
- [臨] 實測：指令自己寫的檔 mtime 一律晚於自己的開始時戳（最少晚 31ms），往前只需放寬 0.05 秒；放寬到 2 秒就會把使用者剛改的檔收進來。
- [臨] 剩下分不出的只有「指令執行那幾秒內別人寫的檔」，這段要當已知限制留著，不要靠加大寬限去掩蓋。

## 行動

- 補算指令改檔：以指令開始時戳減 0.05 秒當 mtime 下界，不用 session 開頭的版控快照比差異
