# session級狀態旗標當回合級用要有新回合改回的點-放新回合入口開頭當場寫回-入口hook逾時被砍尾端寫回跑不到

## 知識

- [臨] session 級的狀態旗標被拿去當回合級用（例：收尾設 done、閘看到 done 就跳過），一定要有「新回合改回」的對應點，不然過期值會讓後面整串閘靜默失效。
- [臨] 改回要放在新回合入口的開頭、當場寫回：入口 hook 可能逾時被砍，放尾端的寫回跑不到。

## 行動

- 看到旗標被讀來決定「這回合跳不跳過」，先找它在哪裡被改回；找不到就在新回合入口開頭補上
