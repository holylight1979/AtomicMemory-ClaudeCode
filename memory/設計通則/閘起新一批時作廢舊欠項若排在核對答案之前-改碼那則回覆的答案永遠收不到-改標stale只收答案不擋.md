# 閘起新一批時作廢舊欠項若排在核對答案之前-改碼那則回覆的答案永遠收不到-改標stale只收答案不擋

## 知識

- [臨] 收尾若先跑「起新一批量測→清掉舊欠項」、後跑「核對收尾文字裡的答案」，AI 在改碼同一則回覆寫的答案還沒核對就被清掉，下一批又全部重問，形成修了又欠。改成舊欠項標 stale：照收答案、不擋，新一批量完再換掉。


## 行動

- 寫或審「改碼就作廢舊結果」的閘：先查核對答案的步驟排在作廢之前還是之後
