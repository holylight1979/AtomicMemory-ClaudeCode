## 知識

- [臨] 結果目錄是多個 session 共用的；「本回合取到 done 就算跑過」會讓別 session 的工作、或開工作之後又改過程式的工作混過。
- [臨] 跨回合取用要核兩件：工作 id 裡的 session 段是不是自己；開工作的時間晚於最後一次改檔。

## 行動

- 跨回合認領共用目錄裡的結果：先比工作 id 的 session 段，再比開工作時間與最後一次改檔時間
