## 知識

- [臨] 實例：做分層 scope 解析時假設 Python 端通用處理所有層級，實跑 `scope="org"` 回 Unknown scope——當時程式根本沒有這個值。用某個值之前先找程式裡的支援清單（列舉、驗證函式、schema enum）。
- [臨] 實例：Claude Code 交給 hook 的 tool_response 不保證是 dict（失敗時可能是字串），只寫一種形狀的程式會在失敗路徑炸掉或誤判；hooks/codex_companion.py、hooks/acceptance_spec.py 都先判 isinstance 再取欄位。外部介面的結果先正規化成同一個結構再判斷。

## 行動

- 用到某個值或介面前：找程式裡的支援清單，或實際取一份成功與一份失敗的樣本
- 讀外部工具結果先處理「不是預期形狀」的分支
