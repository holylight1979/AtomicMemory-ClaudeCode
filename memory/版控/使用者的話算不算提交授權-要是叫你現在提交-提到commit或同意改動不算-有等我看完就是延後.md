## 知識

- [臨] 判準：授權＝使用者這回合有一句是在叫你（或同意你）現在提交：提交動作＋祈使或同意語氣，而且同一則話裡沒有別的子句把它延後（「等我看完 diff」「我確認後」「晚點再說」）。整則話一起看，不是只看含 commit 的那一句。
- [臨] 不算授權：提到 commit 但在講別的事（「commit 訊息寫中文」「commit 要怎麼拆」）、只同意改動本身（「這樣改可以」）、問句（「要 commit 了嗎？」）。程式只核對原句逐字在原話裡、沒被否定，這些句子它都會放行，判斷全在你。
- [臨] 授權範圍照原話：只授權 commit 就只做 commit，指令裡沒被授權的 push 要拿掉；部分授權也是授權，不必再等「上GIT」。
- [臨] 反例：使用者說「測完再一起上」，AI 引用「一起上」當授權——「測完再」是延後條件，還沒測完就不算。

## 行動

- 被 CommitOrder 擋下：把本回合使用者原話整則讀一遍，找「叫你現在提交」的那句；找不到就不提交，收尾列改動與驗證，請使用者下口令
- 找到了：逐字引用那一句，指令只做原話授權的動作
