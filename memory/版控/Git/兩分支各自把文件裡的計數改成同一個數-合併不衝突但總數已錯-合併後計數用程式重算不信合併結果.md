## 知識

- [臨] 兩條分支各自把文件裡「RULES 現有 N 條」從 158 改成 164，字面完全一樣，git 合併不衝突，但實際總數已是 170。合併沒衝突不代表內容對。
- [臨] 同型風險：任何寫在文件裡、兩邊各自加一的計數（規則數、案例數、序號）。合併後用程式重算（如 len(RULES)）再改文件。

## 行動

- 合併後凡文件裡有計數，用程式重算實際數對照，不信合併結果
