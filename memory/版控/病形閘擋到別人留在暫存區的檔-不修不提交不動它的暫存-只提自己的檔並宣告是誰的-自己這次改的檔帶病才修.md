## 知識

- [臨] 被病形閘擋，先查事實再分類：這個 session 我用 Edit／Write 改過的檔＝我的；session 開始時就已經在暫存區、我沒改過的＝別人的。只看這個事實分，不看檔名或病名。
- [臨] 我的檔帶病 → 修病再提交，不准移出暫存或排除。別人的檔帶病 → 不修、不提交、不 restore（不動別人的暫存）；只用 pathspec 提我的檔，寫「不是繞閘｜<別人的檔> 是 session 開始前就在暫存區的別人改動、不屬這次需求，病留給它的主人修」，收尾時回報這件事。
- [臨] 兩類都有就分開處理。例：我改了 a.py（帶病），b.py 是別人的（帶病）→ 修 a.py，只提 a.py 和我其他的檔，宣告只寫 b.py。擋訊息說的「把 ✗ 那幾行改掉再 commit」只適用於我的檔。

## 行動

- 逐檔問：這次我改過它嗎？改過 → 修；沒改過 → 只提自己的檔、宣告寫它是誰的、收尾回報
