# markdown文件裡角括號佔位符要包反引號-裸寫u會被當成底線標籤把後半份文件全畫線

- Scope: global

- Confidence: [臨]

- Created-at: 2026-10-05

## 知識

- [臨] 實踩（2026-10-01）：計畫檔正文裡裸寫 `personal:<u>／role:<r>`（反引號外），Markdown 預覽把 `<u>` 當成 HTML 底線標籤且沒有關閉 → 從那一行起後半份文件全部被畫底線，使用者以為格式壞掉。同類地雷：`<b>`、`<i>`、`<s>`、`<p>`、`<a>` 等單字母或短名佔位符；`<root>`、`<path>` 這類非 HTML 標籤多半只是消失不顯示。
- [臨] 規則：文件／計畫／回覆裡的角括號佔位符一律包在反引號裡，或改用完整字（`<user>`、`<role>`）仍包反引號。檢查法：grep 文件中反引號外的 `<單字母>`。

## 行動

- 寫計畫檔或文件含 `<x>` 佔位符 → 一律包反引號
- 使用者說文件後半被畫線／變粗／變斜 → 先找第一個異常行上的裸角括號
