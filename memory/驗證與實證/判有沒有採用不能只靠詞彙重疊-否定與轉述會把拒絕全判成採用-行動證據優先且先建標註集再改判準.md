## 知識

- [臨] 2026-09-21 對 57 筆人工型標註（AI 標）評估：詞彙重疊判用（v1）precision 0.35、9 筆明說「不要用這顆／已過時」的 rejected 全判 used（9/9）、9 筆只是轉述的 cited 也全判 used——因為否定句和轉述句一定會提到 atom 的關鍵詞，重疊反而更高。改成 v2（否定線索先判 rejected → 路標未 Read 不算 → rescue 特異 token 命中判 used → 轉述句剔除後再比詞彙、共享 ≥6）：P 0.35→0.67、R 1.00→0.84、rejected 誤判 9/9→1/9。
- [臨] 通則：凡是要判「模型／人有沒有真的採用某段知識」，順序是 否定 > 未曾看見 > 行動證據（實際執行的指令、Read 的檔） > 引用剔除 > 詞彙相似；相似度只能當最後的弱證據。而且先建標註集（每筆帶原文窗與理由）再改判準，否則每個改法都只是換一種感覺。
- [臨] 判斷為什麼會寫成這樣：第一版判用是為了「有數字可看」快速寫的代理指標，沒有反例集就上線，之後晉升／回訪全建立在它上面，錯得越久越像對的。

## 行動

- 設計任何「是否採用／是否遵守」的偵測：先收 ≥30 筆含否定與轉述的反例再定判準
- 看到 precision 低但 recall 1.0 的採用偵測：先查否定與引用是否被當正例
