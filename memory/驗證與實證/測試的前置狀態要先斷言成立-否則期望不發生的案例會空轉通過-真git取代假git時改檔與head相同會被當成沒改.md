## 知識

- [臨] 「期望某件事不發生」的案例（不記漏判、不擋、不欠）在前置狀態沒建起來時會空轉通過，只有「期望發生」的對照案會紅，容易誤以為主案已驗到。實遇：把假版控目錄換成真 git repo 後，前一個 session 的改檔內容和 HEAD 相同，被判成「改過又原樣還原」→ 範圍沒結案 → 後面要判的漏判沒有對象，兩個「不記」案空轉通過。前置狀態先斷言成立（結案數、收據數、狀態欄），再斷言結果。

## 行動

- 寫「期望不發生」的案例：先 assert 前置狀態真的建起來了，再 assert 結果
- 測試環境換成更真的實作（假目錄→真 repo）後，重新確認舊的前置步驟在新環境裡還成立
