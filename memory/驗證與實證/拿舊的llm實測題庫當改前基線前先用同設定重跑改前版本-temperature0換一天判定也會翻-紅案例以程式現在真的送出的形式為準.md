## 知識

- [臨]（實測 gemma4:e4b，temperature 0、同 host 同 num_ctx）同一題「卡放題目最前面、材料不附呼叫點」，一週內的舊紀錄判錯，這次重跑判對。舊題庫的判定只能當線索，不能直接當改前紅案例：改前版本要在同一次、同一套設定下重跑，跟改後版本一起記錄。
- [臨] 改前版本要照程式現在真的送出的樣子組（例：判準卡實際是接在擋訊息後面，不是放在題目最前面）。照舊題庫的擺法，改前反而判對、看起來不用修；照真的接法，改前判錯、改後判對，這才是能拿來交付的紅案例。
- [臨] 改後版本從程式抽字句（呼叫真的組訊息的函式），不要手抄：字句再改一輪時實測自動跟上，也不會出現案例綠、實測用的卻是舊字。最後一次改完字句要整批再跑一輪，表上只放最後那輪。

## 行動

- 改前改後實測：改前版本同一次重跑，不沿用舊判定
- 改前版本照現在的實際接法組，改後版本從程式抽字句
- 字句最後一次改完整批重跑，只報最後一輪
