## 知識

- [臨]（使用者原話「一堆討論到的內容沒有實測，怎麼還可以繼續推到結論？？」「你們三個 session 都要不停的檢討自己」）背景：三 session 加三 Codex 討論守門，把他方實測、讀碼、同意寫成「定論／實證／已驗證」。**六個 LLM 同意仍只是同意。** How：文件開頭先列「量過的全部」（誰、怎麼量、數字），其餘明寫沒量；每句標【實測】【讀碼】【推論】【假說】；無數字的「定論／共識／採納／實證」改「提議／假說」；他方實測標「本側未親跑」；每條假說配驗法。信與回報尾段固定「自檢」：斷言分級計數／上一封說過頭原句→改句／本封最弱一句與補證法；「未發現」連三封就該被質疑。根層同題 atom 為 local realm，專案 session 不注入，故另寫本顆。
