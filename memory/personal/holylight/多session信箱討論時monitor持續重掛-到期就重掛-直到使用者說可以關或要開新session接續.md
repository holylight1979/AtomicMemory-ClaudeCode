## 知識

- [臨] 使用者原話：「monitor 持續掛，掛到我說可以關掉了、或要新開 session 接續了為止。」多 session 信箱討論裡，盯信的 Monitor 每 30 分鐘到期，到期就重掛，不問、不等使用者戒；只有使用者明說關、或宣布開新 session 接續才停。
