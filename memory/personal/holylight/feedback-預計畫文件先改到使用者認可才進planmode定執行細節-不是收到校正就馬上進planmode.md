## 知識

- [臨] 使用者原話：「我沒有要你馬上進入 PlanMode，而是要你把文件改到我認可以後，再進入 PlanMode 制定真正執行時的細節。」背景：他說「這份是計劃之前的預計畫文件，我要你從 PlanMode＋多 agent 參與；等你再改好文件，我最終看過同意你才可以開始」，我讀成「現在進 PlanMode」。正確順序：預計畫文件（目標與做法，給人看）→ 使用者認可 → PlanMode（執行細節，多 agent 探索）→ 使用者同意 → 實作。多 agent 可以在改文件階段就用（追來源、蒐原話、盤落點），不等於進 PlanMode。

## 行動

- 使用者說「改好文件我看過同意才開始」→ 先改文件，不進 PlanMode；要用 agent 就直接派 Explore
- 進 PlanMode 前自問：使用者認可的文件在哪？沒有就還不是時候
