## 知識

- [臨] 架構：world.html 為唯一推進引擎（開著就跑/關了暫停），免LLM 引擎(擴散/共識/dev累加/tier解鎖/鎖定/多風格/完工)＋LLM 僅2點(種子 envBrainstorm/定案 envDirection)；發展狀態鏡像於模組級 regionDev:Map、落盤 server `GET/POST /api/world-dev` → `workflow/world-dev.json`。
- [臨] ★零影響隔離鐵則：只**讀**生物個性，狀態只**寫** gitignore 的 world-dev.json，絕不碰 memory/ 樹、_atom_index.json、*.access.json、funnel/atom_write。結構性隔離＝獨立 API+獨立檔，server.js 既有碰記憶路徑一律不呼。驗收＝整段驅動後 `git status` 全空、memory 零 diff（這是核心驗收，非口頭保證）。
- [臨] envLlm fallback 鐵則：LLM(共用 chatBusy 序列鎖+ENV_LLM_MIN_GAP≈4s) 斷網/逾時/JSON 解析失敗一律 fallback＝純前端依個性投票選 family+目錄種子+罐頭台詞，**仍建 proposal/仍鎖定**永不阻塞。每區到 80% 約 2 次 LLM；fallback 命中可 0 次。fast 模式只加速免LLM 路徑，LLM 不加速（單張 3090 序列不成瓶頸）。
- [臨] crack 模型 JSON 解析：rdchat-direct 的 Gemma-4-31B-CRACK 會洩漏 `<|channel>thought<channel|>` 控制 token → 先 `cleanLine` 剝除再 `JSON.parse`，失敗用 `/\{[\s\S]*\}/` 抓第一個物件重試；回傳 family 須∈8 家族白名單否則 fallback。
- [臨] _visiting 接位移軸（守 reconcile-render 鐵律）：跨區串門子讓攜帶想法的生物 lerp 走向他區中心，**只動持久 el._x/_y、絕不改 c.region**，lerp 掛在 tick() 位移軸。覆轍同源：動畫/進行中暫態一律存持久 el / regionDev / 檔，絕不存每 5s 由 buildModel 重建的 model.c（存 c 會每 5s 彈回，見 [[reconcile-render-動畫狀態歸屬陷阱]]）。
- [臨] deterministic 渲染：`placeEnv` 用 seeded LCG(`hash32(region.key+"|"+element.id)`)＝禁 Math.random → 同 (region,element) 每次 render 必同位；同 pos 類用 element.id 字典序排，插入新元素不位移舊的。`el._envSig` 髒檢查 sig 沒變不碰 DOM。
- [臨] 完工門檻＝每區首風格 rank1.dev≥80（次風格續長不影響）；活躍區＝該 region.list≥2（單/空生物區不發展、只留 tier-0 🔥 種子）。/loop 停止＝全部活躍區皆完工。fast 模式下近完工區數十秒即收斂。靜態伺服 :8899 須與 world.html 同層（catalog 走相對路徑、API 跨源打 :3848）。

- 動畫/進行中暫態存 el/regionDev/檔，絕不存 model.c
