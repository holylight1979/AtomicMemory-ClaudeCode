# 多代理分片寫跨版本文件要加跨版一致性檢查與共同決定表-共同決定先查證再發給各代理

## 知識

- [臨] 實測：把上千個 commit 切片、每片一個代理整理＋一個代理對著 commit 挑錯、每版再一個代理寫成頁，單頁都對，但跨版一致性檢查仍挑出 26 個問題：同一功能兩版都寫成新增、同一個概念各版叫不同名字、數字量的對象不同卻接著比、移除了從沒介紹過的東西。分片的代理看不到別版，這類問題只有全局一輪抓得到。
- [臨] 修訂時發給各版代理一份「共同決定」（用語表、命名、跨版寫法）才收斂；但共同決定裡的事實前提要先查證，實例是我寫「v6.0 預設關、用某鍵開」，兩個代理查到 v6.0 根本沒有總開關，只好再修一輪。查不到出處的數字一律刪，不讓代理保留。

## 行動

- 多代理分片寫跨版本文件：整理→挑錯→撰寫之後，固定加一輪跨版一致性檢查和一輪帶共同決定的修訂
- 發共同決定前，先用 git 查證裡面每一個事實前提
