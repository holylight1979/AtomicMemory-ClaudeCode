## 知識

- [臨] 掃碼重構一輪的 SOP（2026-09-03 三輪十六個 commit 磨出來）：① 用縮排深度＋方法行數量化選重災區，同時跑一個獨立第二意見（Codex）只給原話與評判依據不給方法；量化抓結構、第二意見抓正確性，兩邊互補。② 它的斷言逐條讀碼核實標「已核實／推論」再整合。③ 沒自測的方法先補特徵測試（寫現狀行為，預期錯就改預期）再動。④ 純重構一個 commit：只抽方法／查表／拆檔，訊息字串與 return 值不動，證據＝改前後自測報告檔 diff 無差異（不只看計數）。⑤ 行為修正另一個 commit，每項先加會紅的案例。⑥ 自測檔千行單方法要逐案包 try/catch（一案炸掉不拖垃整份報告），可用腳本機械轉換。
- [臨] 不能離線驗的視窗互動改動（右鍵選單、拖曳、資源釋放）報告要明講「只有 build 與 diff 對照」；實機真的抓到回歸（選單 Closed 裡 Dispose → 刪房跳當）。視窗類小改不要與大重構同 commit，回歸才好定位。
- [臨] 一輪一個範圍（三檔或一個模組），收尾給下一輪接續 prompt 列「已整理／只搬過／沒動過」三類檔清單，下一個 session 不用重掃。

## 行動

- 掃碼重構：量化選檔＋獨立第二意見並行，斷言逐條核實
- 無自測的方法先補特徵測試再抽；純重構靠報告檔 diff 無差異當證據
- 純重構與行為修正分 commit；行為修正先加會紅的案例
