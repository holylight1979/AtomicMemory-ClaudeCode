## 知識

- [臨] 原設計者（晚）下班前給對人總控台的夜間授權型態：①需要新工作 session 時總控台自己開分頁、貼開工句、讓調度操控（他會先預開幾個空分頁）；②真的只有他能定奪的事列「待原設計者」等早上，不硬裁；③可關的分頁不關、等他早上處理，但總控台要提醒「關前把該 session 的重要經驗與知識分類收錄」；④授權只給當時那一個對人 session，它 token 用完、換手或工作完成即失效（「失效」只描述對人 session，不限制工作 session 的開立）。
- [臨] 他的夜間目標敘述：當前推進完工之外，把骨架相關盡量做完，或推到「使用上體感 OK、不擾民、不誤判、下次好接續」；要站在他的視角推進。token 總量有限（本週開發不完整套），所以並行數看 token 餘量，每軌交付附自足接手單。
- [臨] 做法：接到授權就把規矩寫進接續單（標明授權對象與失效條件）、開一份「早上待辦」檔（要他動手的事放最前面：關分頁前收割、Reload Window、要他親手打的題句、要他答的放行），並即時通知調度改作業方式。

## 行動

- 收到下班授權：先寫接續單規矩與早上待辦檔，再通知調度
- 可關分頁一律寫進早上待辦並附「關前收錄知識」提醒，不自己關
- 只有原設計者能定奪的事列待原設計者，不硬裁；其餘該做就做
- 換手時明寫夜間授權隨本 session 失效，接手者要新開 session 一律等原設計者
