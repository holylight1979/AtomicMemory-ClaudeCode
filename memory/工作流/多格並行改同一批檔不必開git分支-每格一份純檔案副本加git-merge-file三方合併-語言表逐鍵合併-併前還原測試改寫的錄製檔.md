## 知識

- [臨] 約 25 個子代理同時改 900 檔的同一批檔可行：共同基底＋每格一份純檔案副本＋主 session 用 git merge-file 三方合併，不開分支、不 commit；實測多數格零衝突，衝突多是兩格各加一行 import。
- [臨] 開工前先實算各格會碰哪些檔，不信交接單的「無檔案重疊」：這次寫無重疊，實算平台與語言表重疊 35 檔。
- [臨] JSON 語言表不要走文字合併，改逐鍵三方（這格改了且主線還是基底值才取這格）；只比同鍵不同字會把另一格的改值當衝突吃掉。
- [臨] 機械改名這類工作做成可重入腳本、全部合併後在主線重跑一次，就不會和別格衝突，還涵蓋別格新增的字。
- [臨] 併前要還原該格被測試改寫的錄製檔（一格中過 75 個 cassette）；跑測試一律在暫存複本。

## 行動

- 開工前實算各格檔案重疊，重疊就用純檔案副本加三方合併
- 語言表逐鍵合併，機械改名留到最後重跑
- 併前比對基底，還原測試改寫的錄製檔
