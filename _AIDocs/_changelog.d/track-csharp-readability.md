## 2026-10-23 svn 專案的 C# 也量閱讀路徑；Python 也改成超線才有字
- **AI 寫程式時會看到的**（守門總開關 v6 開時，寫碼回合收尾背景量）：
  - **svn 工作副本裡改 .cs 也量**：原本閱讀路徑只認 git，svn 專案（例：sgi_client）改了 C# 什麼都不量。現在照既有的版控偵測（最近的 `.git`／`.svn`）分出 svn，一樣只讀改到的檔加一跳上下游，對 BASE 比，超線才問。svn 裡的 Python 仍不量（Python 的比較要 git 歷史，只報個數）。
  - **Python 沒超線就不附數據**：原本 Python 改動不管有沒有到門檻，都把尾行、可評級、最差一條與函式級數據表附進收尾結果（被別的閘擋時會一起送進模型）。現在一個根沒有到門檻的條目，那段數據不附，只印 stderr、guard log 記 event=measured；到門檻照舊整段附上、照舊問。量不出來的一句原因、沒量到的檔數照附。
