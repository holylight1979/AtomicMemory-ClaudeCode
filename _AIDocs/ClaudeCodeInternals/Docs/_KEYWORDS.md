# Claude Code 官方文件 — 關鍵字反查與記憶系統接點彙整

## 記憶系統接點（各頁導讀卡「記憶系統接點」欄彙整，只列有內容的）

**01-getting-started**
- [chrome](01-getting-started/chrome.md)：瀏覽器工具屬 MCP 類工具，可被 PreToolUse hook 攔截；分頁隨 /clear 清理。
- [claude-code-on-the-web](01-getting-started/claude-code-on-the-web.md)：雲端會話不載使用者層設定/外掛；SessionStart hook 在雲端有逾時；與本機記憶檔層不共享。
- [claude-projects](01-getting-started/claude-projects.md)：project 有 Memory 檔與指示注入每個執行緒，類似 SessionStart 注入；執行緒僅取 CLAUDE.md，不取 hooks/skills。
- [claude-tag](01-getting-started/claude-tag.md)：有頻道記憶與「依地點跟隨」記憶範圍模型，可對照 atom 的 scope；沙箱臨時，擴充走 plugins/skills/connectors。
- [computer-use](01-getting-started/computer-use.md)：內建 MCP 伺服器可用 /mcp 開關；工具名可被 hook matcher 比對；鎖檔機制可類比多 session 互斥。
- [desktop](01-getting-started/desktop.md)：launch.json/受管設定與設定分層同構；跨會話傳訊是機制事實，涉多 session 協作；Desktop 沿用同一 hooks/skills/MCP。
- [desktop-scheduled-tasks](01-getting-started/desktop-scheduled-tasks.md)：任務以 SKILL.md 形式落在 ~/.claude/scheduled-tasks/，與 skills 目錄機制同形；Desktop 排程會話同樣觸發 hooks。
- [jetbrains](01-getting-started/jetbrains.md)：PreToolUse hook 若白名單 MCP 工具需知 mcp__ide__getDiagnostics 存在；Read deny 規則同時擋 IDE 選取內容。
- [platforms](01-getting-started/platforms.md)：「配置、專案記憶、MCP 在本機介面間共享」與記憶系統的檔案層一致；無新衝突。
- [remote-control](01-getting-started/remote-control.md)：--spawn worktree 與多會話隔離同概念；CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC 會使其不可用；遠端所見斜線命令受限。
- [routines](01-getting-started/routines.md)：提示詞與 API text 的信任分離可借鏡；與 hooks 無直接關係；雲端 run 不載入本機記憶檔，只讀 clone 的 CLAUDE.md。
- [slack](01-getting-started/slack.md)：Slack 訊息成為任務背景資訊（類似外部輸入來源）；無記憶接點。
- [vs-code](01-getting-started/vs-code.md)：擴充功能走同一 settings.json/hooks/MCP 體系，記憶注入 hook 同樣生效；cloud 會話不載入使用者層外掛。
- [claude-security](01-getting-started/claude-security.md)：外掛提供斜線命令與 /workflows；結果落成時間戳目錄於 repo；與 security-guidance 分工（寫時 vs 掃描）。
- [code-review](01-getting-started/code-review.md)：服務讀 CLAUDE.md 與 REVIEW.md；本機 /code-review 只讀 CLAUDE.md，兩者是不同工具。
- [code-review-customize](01-getting-started/code-review-customize.md)：REVIEW.md/CLAUDE.md 分層（根+子目錄）與 CLAUDE.md 載入規則同構；審查讀的是預設分支版本。
- [code-review-local](01-getting-started/code-review-local.md)：審查以 forked subagent 跑，不佔主 context；--fix 在 checkpoint 外屬 context/回溯管理要點。
- [github-actions](01-getting-started/github-actions.md)：claude_args 可傳 CLI 旗標；plugins/plugin_marketplaces 與 settings 輸入可帶入 settings/外掛；CLAUDE.md 為 CI 規則來源。
- [github-enterprise-server](01-getting-started/github-enterprise-server.md)：外掛市集預註冊與白名單走受管設定（extraKnownMarketplaces/strictKnownMarketplaces 類機制），屬設定分層。
- [security-guidance](01-getting-started/security-guidance.md)：以 hook 式時機運作（編輯後、回合結束、commit/push）並附加警告進下一步 context；首次在 ~/.claude/security/ 建 venv；每警告每會話每檔每樣式僅一次。
- [ultrareview](01-getting-started/ultrareview.md)：claude -p '/code-review ultra' 取不到發現，需用子命令；--trust-workspace 為非互動信任旁路；上傳依雲端會話打包規則。
- [how-claude-code-works](01-getting-started/how-claude-code-works.md)：context 管理：CLAUDE.md 與自動記憶每個 session 開頭載入、compact 後從磁碟重注入；system-reminder 是 Claude Code 自己夾帶指令的機制；session 逐字稿路徑 `~/.claude/projects/` 可供外部工具讀
- [features-overview](01-getting-started/features-overview.md)：設定分層與 context 載入時機的權威對照表：CLAUDE.md 全載、skill 描述常駐、MCP 只載名稱、hooks 零成本；hooks 全部合併觸發（不覆寫），可與其他來源的 hook 並存；hook 輸出會進 context
- [claude-directory](01-getting-started/claude-directory.md)：設定分層與檔案位置：專案 vs `~/.claude`、commit 與否；自動記憶目錄 `projects/<project>/memory/` 免於保留掃描；`rules/` 僅 `paths` frontmatter；逐字稿明文含已載入的指令檔；保留掃描只處理文件列出的路徑
- [context-window](01-getting-started/context-window.md)：SessionStart hook 可用 matcher `compact` 在壓縮後重注入內容（記憶注入可借用）；CLAUDE.md/自動記憶/無 paths 規則 compact 後從磁碟重注入，hook 先前注入的 context 則被摘要而非保留；PostToolUse hook 輸出進 context；`/context all` 可驗證載入清單
- [prompt-caching](01-getting-started/prompt-caching.md)：關鍵：session 中途改 CLAUDE.md／自動記憶不會即時生效，重注入時機只有 session 開始與 `/clear`、`/compact`；系統層（工具定義）變動比對話層貴，MCP 工具增減會影響快取；系統提示內嵌自動記憶路徑
- [memory](01-getting-started/memory.md)：直接對應記憶系統：(1) 原生 auto memory 目錄 `~/.claude/projects/<project>/memory/` + `MEMORY.md` 200 行／25KB 上限，與自製 atom 系統並存時路徑與預算要分開；(2) CLAUDE.md 是 user message 非 system prompt、compact 後從磁碟重注入；(3) `InstructionsLoaded` hook 可觀測載入；(4) `~/.claude/rules/` 無 paths 者啟動即載；(5) `autoMemoryDirectory` 可指向自訂目錄；(6) 寫 MEMORY.md 後 Claude Code 會量測並提醒/回錯；(7) `@import` 可把外部檔案併入 CLAUDE.md（本機已用 @IDENTITY.md 等）
- [sessions](01-getting-started/sessions.md)：hook 輸入含 `transcript_path`，SessionEnd hook 可讀完整逐字稿（對話萃取可借用）；session 以 cwd 為鍵；多 session 同時 resume 同一 ID 會交錯寫同檔（協作衝突點）；自動記憶與逐字稿共用 `<project>` 目錄命名規則
- [best-practices](01-getting-started/best-practices.md)：最直接的「規則強制」依據：「一再強調仍漏掉 → 改成 hook」；Stop hook（exit 2＋stderr）可作為收尾閘；`--bare` 會略過 hook 與 CLAUDE.md（headless 腳本不會載入記憶注入）；hook 類型含 http 與 MCP tool；Stop hook 連續封鎖八次後放行（與自製 guardian 擋次數設計相關）

**03-plugins**
- [plugins/overview](03-plugins/plugins__overview.md)：plugin 可封裝 skills/agents/hooks/MCP/設定；啟用後名稱與描述每回合佔 context，hooks 與 MCP 隨每個工作階段啟動。
- [plugins/code-intelligence](03-plugins/plugins__code-intelligence.md)：LSP 診斷在編輯後以 `Found N new diagnostic issues` 回饋；plugin 可包含 `.lsp.json` 元件。
- [plugins/install](03-plugins/plugins__install.md)：enabledPlugins 依 user/project/local 設定檔分層；plugin 啟用變更要 /reload-plugins 才進現有 session。
- [plugins/security](03-plugins/plugins__security.md)：plugin 的 hooks/MCP/monitors 不受權限規則與沙箱約束；hooks 以使用者權限跑；skills/agents 內容會進 context 當指令。
- [plugin-evals](03-plugins/plugin-evals.md)：eval 在隔離的 `claude -p` 子 session 跑，不載使用者設定/CLAUDE.md/記憶；grader 可檢查工具呼叫與檔案；可用於驗證 skill 是否被觸發。
- [plugins/cli-hints](03-plugins/plugins__cli-hints.md)：Bash/PowerShell 工具與 hook 命令的環境變數有 `CLAUDECODE=1`；hook 命令輸出中的 hint 標籤會被剝除。
- [plugins/components](03-plugins/plugins__components.md)：plugin 內 hooks 可用 hooks.json 封裝，事件與設定檔 hooks 相同；hook 命令可取 CLAUDE_PLUGIN_ROOT/DATA 路徑；MCP 工具名帶 plugin 前綴供 matcher 比對；sensitive userConfig 存安全儲存而非 settings.json。
- [plugins/create](03-plugins/plugins__create.md)：既有 .claude/ 的 skills/agents/hooks/.mcp.json 可原樣搬入 plugin 根目錄；plugin 根的 CLAUDE.md 不載入，須寫成 skill。
- [plugins/dependencies](03-plugins/plugins__dependencies.md)：plugin 依賴宣告在 manifest，安裝/啟用時自動連帶安裝同 scope，停用時被需要者會拒絕；/reload-plugins 會補裝缺的依賴。
- [plugins/measure](03-plugins/plugins__measure.md)：plugin 的名稱與描述屬 always-on context 成本；有 OTel 事件可統計 plugin 載入/skill 啟動；hooks 不吃模型 context。
- [plugins/host-marketplace](03-plugins/plugins__host-marketplace.md)：marketplace 可由 `.claude/settings.json` 的 extraKnownMarketplaces 登錄給整個 repo；自動更新與憑證處理在背景以使用者機器 git 執行。
- [plugins/relevance](03-plugins/plugins__relevance.md)：relevance 訊號會看 Claude 讀寫的檔案路徑、自動載入的 CLAUDE.md 與執行的 shell 命令名稱（本機比對）。
- [plugins/mods/admin](03-plugins/plugins__mods__admin.md)：受管 PreToolUse hook 在 mod 鏈之前執行；mod 可由組織設定控制與審計；plugin.register 事件可程式化審查他人 mod 的呼叫清單。
- [plugins/org](03-plugins/plugins__org.md)：受管設定可強制 enabledPlugins、限制 hooks 只來自受管/強制 plugin；各 surface(終端/-p/雲端)套用時機不同；種子目錄供離線環境。
- [plugins/mods/api](03-plugins/plugins__mods__api.md)：$.store 為跨 session 共用的鍵值儲存(上限 4 MiB)；$.session.send/receive 可做 session 間訊息；$.settings.read、$.fs 可讀寫本機檔案。
- [plugins/mods/create](03-plugins/plugins__mods__create.md)：mod 的 hook 檔案用 `$.xxx.yyy` 完整寫法才能被靜態分析；內建 skill 可由 Claude 代寫。
- [plugins/mods/events](03-plugins/plugins__mods__events.md)：mod 事件鏈與設定檔 `PreToolUse` hook 有固定交錯順序（受管 hook 最先）；`prompt.submit`/`prompt.context`/`prompt.compose` 可注入或改寫送入模型的文字；失敗可 fail-closed。
- [plugins/mods/interface](03-plugins/plugins__mods__interface.md)：mod 可用 `$.state`(session 存活)、`$.store`(跨 session 持久)保存資料；介面僅為顯示層，不影響記憶注入。
- [plugins/mods/overview](03-plugins/plugins__mods__overview.md)：mod hook 與設定檔 hooks 並行；mod 可在 prompt.submit、session.start、tool.call 等事件介入（含 prompt.context 注入），並可 $.session.send 傳訊給其他 session。
