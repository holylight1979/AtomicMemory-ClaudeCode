# 範例

> 尋找完整、可執行的 Agent SDK 專案或 Claude Cookbook 中的引導式配方，以符合您想要建置的內容。

此頁面會引導您前往完整、可執行的 Agent SDK 專案和引導式 Claude Cookbook 配方。應用程式位於 [`claude-agent-sdk-demos`](https://github.com/anthropics/claude-agent-sdk-demos) 儲存庫中，Python 配方位於 [Claude Cookbook](https://platform.claude.com/cookbook) 中。

## 先執行最小化代理

如果您還沒有使用 SDK 建置任何東西，請在完整應用程式之前從以下其中一個開始：

* [Agent SDK 快速入門](https://code.claude.com/docs/zh-TW/agent-sdk/quickstart.md)：在 TypeScript 或 Python 中建置您的第一個可運作的代理，包括設定步驟。代理會在範例檔案中尋找並修復錯誤。

* [Hello World](https://github.com/anthropics/claude-agent-sdk-demos/tree/main/hello-world)：當您想從儲存庫程式碼開始時要複製的最小化 TypeScript 專案

## 探索示範應用程式

[`claude-agent-sdk-demos`](https://github.com/anthropics/claude-agent-sdk-demos) 中的應用程式是本機開發的示範，從電子郵件用戶端到多代理研究系統。複製其形狀與您正在建置的內容相符的示範。

## Fork 完整專案

若要使用 Python SDK 打造購物 agent 或商家 agent，請從 [Claude for commerce 參考實作](https://platform.claude.com/docs/en/about-claude/use-case-guides/commerce-agents)開始。

## 進行 Python 配方

Claude Cookbook 的 Agent SDK 系列是一系列配方，每個配方都是 Python 筆記本，從簡單的研究代理進展到複雜的多代理系統。每個筆記本都以前一個為基礎，引入新的概念和功能。從[單行研究代理](https://platform.claude.com/cookbook/claude-agent-sdk-00-the-one-liner-research-agent)開始並向前進行。

如需跨 Claude 產品的配方，請參閱完整的 [Claude Cookbook](https://platform.claude.com/cookbook)。
