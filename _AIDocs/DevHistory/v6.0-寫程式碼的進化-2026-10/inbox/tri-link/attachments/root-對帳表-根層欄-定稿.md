**Codex 獨立填表與分歧**（同材料、唯讀、先不看草稿；回覆全文在 `attachments/root-codex審R5回覆.md`）

- Codex 的表幾乎每項都填「看程式知道：紀錄」——它只能證實程式與文件存在，看不到我這個 session 跑過的 E2E 與 777 案結果，所以把我的【試過】多半降成「部分」。這不是分歧，是它的視角限制；我保留【試過】但在表裡註明「Codex 看不到執行結果」。
- 真分歧三條：①#10 它判「推翻」——全貌開頭把 live session 成因寫成定論、第三節卻標推測：**它對，已改**。②核心一項它判「打到周邊」：閘只管「材料有沒有送到、格式有沒有交」，沒驗證「是否綜觀、是否找到根因」：**對一半**——閘本來就是「讓它有東西看」的前提工程，效果要靠量尺驗，表裡已寫 0 實測；但「定位三行可以敷衍」（W1）成立，已改成照抄範本不算交。③#7d／7e 它說「不足以斷言三邊全沒做」：**對**，SGI 已確認未做並給量法，TSLG 等 T11。
- 它抓到的程式缺陷：B1 deny 時沒帶卡、B2 兩部位定位互相覆蓋、B5 glob 被短前綴搶走、W1 照抄範本就過、W2 跨部位讀檔漏計、W4 放行時 state 沒落盤、W10 config 說明寫錯 log 名——七條全對、全修、各加一案測試。B3（Bash 改檔不經閘）、B4（無 transcript 時放行）是 fail-open 設計：B4 改成放行但提醒；B3 記為已知邊界。W3／W5～W9 是量尺的限制（Bash 讀檔擷取不全、edits 是嘗試數不是重修輪數、目錄數不等於綜觀程度、14 天雙 fix 不等於同問題），都寫進「還缺」。
