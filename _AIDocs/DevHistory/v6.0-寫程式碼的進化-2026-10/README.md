## 路徑變更說明

- 卡片（atom）的 `Source:` 欄寫的是搬家前的原位置（同上表「原位置」欄的信箱路徑），對應本資料夾 `inbox/` 底下同名檔；Source 是落檔當時的出處，不回改。
- 卡片 `Source:` 指向 `workflow/v6-inbox/…`（v6.0 根層派工信箱）的，原件已於 2026-10-14 清理刪除、沒有搬進本資料夾；重要內容收在上表三份新檔，歷程在 `工作紀錄.md`。
