## 知識

- [臨] 實例：派工單寫著「總控台延展補充表另外產出、等看過再補進來」，那張表其實早已推上去、也已裁定；新接手的對人總控台只讀派工單、沒對 git log，就要求重開一條文件軌。
- [臨] 做法：每次裁定把某件事做完或改向，當場回頭改派工單／接續單上提到它的舊句，改成「已產出：<路徑>、<commit>」。收到開新軌請求時，先用 git log 與信箱查是否已做完。

## 行動

- 裁定改向後即時改派工單上的舊句
- 收到開軌請求先查是否已有產物
