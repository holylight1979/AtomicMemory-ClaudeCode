## 知識

- [臨] 判一個回合要不要跑 v6 守門：本回合已用工具改程式檔（writes_code，含 .bat／.cmd 與判不出目標的寫入）才算寫碼回合；關鍵字意圖（classify_intent）只用來送提示，不當開關。
- [臨] 兩個會讓減量白做的錯法：「狀態在就算」——跨回合常駐的狀態（例：整天掛著的寫碼目標）會讓每回合都被算成寫碼回合；「關鍵字就算」——使用者原話「要算的是啟動改 code 的行為、以及改 code 的工具，不然範圍會擴散」。
- [臨] 補一層區分：「守門」（擋、瘦身注入、收尾檢核）不認關鍵字意圖，但「要趕在第一次改檔前到的提示」可以認關鍵字意圖，因為寫碼回合要到第一次改檔才成立，那時提示已經來不及。

## 行動

- 改 coding_turn 或任何「只在某類回合啟動」的判法前，先問：這個訊號會不會跨回合殘留？會就加「本回合」條件
