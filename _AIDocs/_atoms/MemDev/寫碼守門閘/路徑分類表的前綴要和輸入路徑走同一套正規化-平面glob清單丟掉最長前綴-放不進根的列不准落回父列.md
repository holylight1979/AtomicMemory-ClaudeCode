## 知識

- [臨] 用「路徑屬哪一列」做豁免（例：部位表類別 knowledge 不欠案例）時，錯的方向一律是 fail-open：真程式被豁免。codex 連兩輪找到同一類：① 輸入路徑帶 `..` 或 8.3 短名，比不到 knowledge 父列底下的 code 子列；② 表上子列寫成 `./docs/build/`，只正規化輸入、沒正規化前綴，子列落空。正解：前綴與路徑走同一套根相對正規化（消 `./`、`..`、斜線、大小寫）；根以下帶短名、前綴放不進根（跳出根、絕對、整個根）都算「判不出」，判不出就不豁免。
- [臨] 不要把分類表放平成 glob 清單給規則用：平面清單沒有「最長前綴優先」，knowledge 父列底下的 code 子列會被父列的 glob 吃掉。也只認錨在專案根的命中，子字串命中（tools/memory/x.py 撞到 memory/）一律不豁免。純規則模組不讀檔時，由呼叫端查表後把「類別」當事實傳進去。

## 行動

- 寫任何「屬哪一區就豁免」的判法：前綴與路徑同一套正規化，判不出就不豁免
- 測試必有「knowledge 父列＋code 子列」配對，子列寫成 `./`、`..`、反斜線、大小寫、短名各一案
