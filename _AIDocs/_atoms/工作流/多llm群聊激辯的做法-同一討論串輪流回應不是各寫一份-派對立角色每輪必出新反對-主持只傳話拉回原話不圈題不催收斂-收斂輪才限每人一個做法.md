## 知識

- [臨] 使用者要的「多 LLM 激辯」是同一個討論串裡輪流讀整串、點名回別人的話（同意／反駁／追問），不是各寫一份分析再由主持人拼；被糾正兩次（「不是各自分析」「我本以為可以至少 10 回合」）。做法：共用一個 thread.md，每輪固定順序、每人 append 一段；Claude 方用同一個 agent 續談（SendMessage），Codex 與無頭 claude -p 每輪給路徑讓它自己讀整串（整包塞命令列會超過 Windows 長度上限）。
- [臨] 收斂太快通常是主持人造成的：第 0 輪就把題目圈成幾個待決分歧、每輪叫大家「往收斂推」，兩輪就握手。真激辯的規則：派對立角色（使用者立場代理人、無用論、原話稽核、未解題型辯護、跳題稽核）；每人每輪必出至少一個新反對或新證據，只重述算棄權；每點標服務使用者哪一句原話；主持人只傳話、補實測事實、發現考古或飄移時貼公告拉回原話；收斂輪才限每人只准一個做法（≤ 5 行：哪一刻、誰做、做什麼、怎麼閉環、怎麼驗），攻防只打必要性與簡單性。
- [臨] 代價（實測一場 12 輪五方）：Claude agent 續談每輪約 5～10k，整場每方 15～18 萬；Codex 每輪 2～3 萬不吃 Claude 額度；無頭 claude -p 另一型號每輪約 1 萬。fork 一個 10 萬起跳，不用於辯論。

## 行動

- 使用者說「多 LLM 激辯」「討論群」：開共用討論串、派對立角色、輪流回別人的話，不各寫一份拼湊
- 主持人不圈題不催收斂；發現考古、飄移時貼公告拉回使用者原話；使用者說要收斂才開收斂輪、每人只准一個做法
- 外部模型（Codex、claude -p 別型號）每輪給路徑讀整串，不把整串塞命令列
