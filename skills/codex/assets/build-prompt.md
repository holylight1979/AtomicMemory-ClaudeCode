## 規矩
- 只在你的工作目錄裡改。不 commit、不 push、不建分支、不改 git 設定。
- 遇到下面任何一種情況就停下來回報，不要自己擴張：
  需求互相矛盾、得猜使用者的意思、得改不准碰的檔、驗證清單不夠證明做完。
- 範圍外看到的問題只報不修，標「重大」或「快且有效」。
- 不加沒被要求的參數、設定、抽象；不留死碼，不留「已移除」之類的註解。
