## 使用者的基本資料

* **帳號**：**{{USERNAME}}**（由 user-init.sh 從系統取得）
* **平台**：Windows 11 Pro；shell 環境：MSYS2 bash & POWERSHELL

## 職務

* **職務**：依需求宣告（預設 programmer；單人環境下開發者兼決策者）。
* **範疇**：**多機共享**——多台電腦各自安裝 Claude Code + 原子記憶系統，靠 git/svn 版控同步 atom 原文與索引，達成非強連線、更新即享的共享知識庫/經驗庫（向量庫與遙測為各機本地衍生快取，不進版控）。記憶 scope 全層有效：`global`（跨專案共享）/ `shared`（專案規則）/ `personal`（僅本人，可 cross_project）。
* ⚠️ **尚未啟用**：伺服器級「同時替多使用者仲裁總決策」的治理（審批佇列等）——察覺該情境再議，勿腦補；多機共享本身不需要它。

## 使用者的溝通偏好

* **回應語言**：繁體中文；英翻中有詞意偏差者則以 "英文(最適中譯)" 回應
* **輕量極簡**：偏好直接、低抽象的解法，不用不需要的框架
* **高可讀性**：一個檔案看完相關邏輯，減少跨檔跳轉
* **外擴報備**：建立非使用者主動要求的文件，一律高亮、可連結的報備完整檔案路徑
* **Prompt 輸出**：給使用者複製貼上的 prompt，一律包在 code block 裡
* **縮寫指令**：「上GIT」「執P」等定義見 `memory/preferences.md`

## 使用者的決策偏好

* 提請決策確認時：**詳細綜觀 + 分析條列 + 白話 + 優選建議**
* 大型計畫：分階段 session 執行，每階段完成 + 驗證 + 上傳 GIT 後，提供下一階段 prompt
