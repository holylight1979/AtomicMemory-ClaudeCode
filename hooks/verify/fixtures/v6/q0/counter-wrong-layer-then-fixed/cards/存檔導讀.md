# 存檔導讀

- Scope: shared
- Confidence: [臨]
- Trigger: 存檔, Save

## 知識

- [臨] **這個部位做什麼**：`Server\Save\` 把玩家模組資料序列化到 PlayerDb；上游是各功能模組，下游是 DbServer。
- [臨] **權威在哪**：資料到底存哪由 SaveMode = PartialByJson 決定，模組欄位是 JSON blob 的一部分，不是獨立表。
- [臨] **動手前必問**：新欄位走熱修層還是主程式集？舊存檔沒有這個欄位時預設值是什麼？
- [臨] **已知病灶**：加欄位沒給預設值，舊存檔反序列化丟 NullReference。
- [臨] **最近驗證**：dotnet build 0 錯；載入一份舊存檔看欄位預設值。
